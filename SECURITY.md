# Seguridad

Gracias por ayudar a mantener seguro Pared Viva.

## Reportar una vulnerabilidad

No abras un issue público si el problema puede afectar fondos, claves, datos personales o la integridad de los contratos. Escribí al equipo por el canal privado acordado o contactá a los maintainers por GitHub.

Incluí:

- descripción del problema;
- contrato, commit o URL afectados;
- pasos para reproducirlo;
- impacto esperado;
- transacciones o cuentas públicas relevantes, si las hay.

No incluyas claves privadas, seed phrases ni datos personales innecesarios.

## Estado actual

El despliegue actual es **testnet** y no debe recibir fondos reales. Antes de mainnet se requiere revisión de seguridad independiente, gestión segura de claves y un plan de respuesta a incidentes.
